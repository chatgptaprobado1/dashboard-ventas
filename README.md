\# Dashboard Comercial de Ventas



Aplicación web en Streamlit que convierte el dashboard comercial de Google Colab

en una app interactiva.



\## Contenido

\- KPIs: ventas totales, unidades, ticket promedio, producto top y mejor vendedor

\- Ventas por producto (barras)

\- Participación por vendedor (gráfico circular)

\- Tendencia de ventas y unidades por producto

\- Predicción IA (regresión lineal) con días a proyectar

\- Filtros por vendedor y producto



\## Ejecutar





pip install -r requirements.txt

python -m streamlit run app.py
